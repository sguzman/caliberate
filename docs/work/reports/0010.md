# Work report: 0010 GUI library service read path

## Summary

Migrated the visible GUI library browse read path to the library service facade.
Book rows are loaded through bounded `LibraryCatalog::query_summary_page` chunks,
the six browser facet lists come from `LibraryCatalog::list_facets`, and non-empty
`SearchScope::All` searches use `LibraryCatalog::search_books`. Existing local
filters, sorting, saved-search persistence, details, editing, and mutations remain
in place. The old `MetadataCache` browse dependency and `BookRecord` presentation
mapping were removed from this read path.

Added pure summary-to-row mapping tests, optional-field coverage, and a bounded
multi-chunk loader test.
