# 0026 — Bounded restartable bulk source adoption

## Summary

Implemented bounded bulk adoption for source-dependent logical formats. Candidate selection is source-specific, deterministic, keyset-paged, and uses the lowest reference asset ID for each logical format. Page size is hard-bounded at 500 and the invocation remains bounded by a conservative maximum format count.

The library service is dry-run by default and delegates every applied candidate to the existing `adopt_format(...)` primitive. It processes sequentially, continues after individual failures, retains reference assets, reports complete aggregate counters with bounded problem details, and derives restartability from canonical managed-copy state. Catalog dependency and managed-backed counts are reported before and after. Progress is observed by the CLI on stderr; machine mode emits one JSON object on stdout.
