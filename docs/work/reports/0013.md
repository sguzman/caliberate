# Task 0013 report — GUI service browser filters

## Summary

Visible GUI browser Include/Exclude filters now flow through typed
`LibraryQuery::metadata_filters`. Summary loading preserves that base query
while applying bounded ID-ordered chunks, so `all_books` is the complete
service-browser-filtered working set. Local row filtering no longer evaluates
browser filters.

## GUI → service mapping

`Authors`, `Tags`, `Series`, `Publishers`, `Ratings`, and `Languages` map
one-to-one to the corresponding `LibraryMetadataFilterField`. `Include` and
`Exclude` map one-to-one to `LibraryMetadataFilterMode`. Filter values are
copied exactly without GUI lowercasing, parsing, or reinterpretation.

## Behavior intentionally remaining local

Format filtering, News-only filtering, scoped search narrowing, and existing
sorting/grouping/secondary-sort presentation remain local. Facet population
continues to use the existing global facet service path. Virtual-library
filter persistence is unchanged.
