# Work report: 0010.3 Calibre smoke import metadata

## Summary

Updated the `en_nonfiction` development bootstrap with a Calibre-specific
filename parser. It splits at the last ` - ` separator, treats the portion
before it as the title, preserves deterministic multiple-author splitting for
`&`, `and`, and comma-separated names, and leaves separator-free names without
an invented author. The generic Rust metadata parser was not changed.

The generated smoke config now points to the dedicated
`.cache/caliberate/data/en-nonfiction-dev.sqlite` database. The optional
`-Reset` switch removes only that database and its SQLite WAL/SHM sidecars,
never the normal database or source ebooks. The default remains non-destructive.
After indexing, the script applies the parsed title/authors through `calibredb`
to the dedicated index and prints the exact GUI launch command using the
generated config. The root script is now a delegating wrapper.
