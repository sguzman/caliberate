# 0005 — Library-domain content locator

## Summary

Added `LibraryContent` and `LibraryCatalog::resolve_content` in the library
crate. The resolver delegates book and asset lookup to existing database APIs
and preserves the OPDS selection rule: prefer the first `copy` asset, then the
first asset in database order, then the logical book path when no assets exist.
Missing books return `None`, and the returned format always comes from the
logical book record.

Added focused temporary-database tests covering copied-asset preference,
first-asset fallback, logical-path fallback, missing books, and logical format
preservation.

- `crates/library/src/catalog.rs`
- `docs/work/ready/0005-library-content-locator.md` (moved to `docs/work/done/`)

No server, GUI, database schema, SQL, filesystem checks, or configuration
