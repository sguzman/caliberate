# 0003 — Read-only library catalog facade

## Summary

Added the first read-only library-domain seam over the existing database. The
library crate now depends on `caliberate-db`, exposes `catalog`, and provides a
`LibraryBook` DTO plus borrowed `LibraryCatalog` facade for list, get, and
search operations. All operations delegate to existing `Database` methods;
no SQL or database behavior was added to the library crate.

Added focused temporary-database tests covering multiple-book listing,
existing and missing ID lookup, and search results as library DTOs.
