# Work report: 0010.2.1 pane drag and emergency layout

## Summary

Pane width persistence now distinguishes separator interaction from passive
runtime clamping. A genuine drag is persisted even when the stored preference is
above the 720 px runtime maximum; width changes caused only by layout clamping
remain transient. The normal 200 px drag floor and prior preferred-width
restoration behavior remain intact.

When the window cannot fit the requested auxiliary panes at 200 px while
retaining the 480 px central target, the runtime temporarily suppresses Details
first, then both auxiliary panes at still narrower widths. The configured
Browser/Details visibility flags are not changed, so panes return automatically
when space is restored and manual collapse state remains persistent.
