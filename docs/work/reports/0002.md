# 0002 — Cross-platform CI baseline

## Summary

Added a GitHub Actions workflow that validates the workspace on
`ubuntu-latest` and `windows-latest` for pushes to `main` and pull requests
targeting `main`. Each matrix job installs stable Rust, uses Cargo caching,
and runs formatting, locked workspace checking, and locked workspace tests.

## Files changed

- `.github/workflows/cross-platform-ci.yml`
- `docs/work/ready/0002-cross-platform-ci.md` (moved to `docs/work/done/`)
- `docs/work/reports/0002.md`

No Rust/application source, product, architecture, or roadmap files were
changed.

## Validation

All commands ran in the native Windows Codex environment:

- `cargo fmt --check` — passed.
- `cargo check --workspace` — passed.
- `cargo test --workspace` — passed; all workspace tests passed.
- `cargo check --workspace --locked` — passed.
- `cargo test --workspace --locked` — passed; all workspace tests passed.
- Workflow YAML was manually inspected for valid GitHub Actions structure,
  matrix expansion, triggers, action usage, and step commands.

The workspace emitted its existing GUI warning backlog during compilation;
there were no errors or test failures.

## Risks and caveats

GitHub-hosted Linux and Windows runners were not independently executed from
this environment; the workflow itself will provide that verification after
integration. The local validation was performed natively on Windows.

## Deviations

None.
