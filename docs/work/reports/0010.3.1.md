# Work report: 0010.3.1 bounded smoke discovery

## Summary

Replaced the smoke-library discovery pipeline with an incremental directory traversal. Positive limits now stop as soon as the requested number of supported ebook files has been selected. Full traversal remains available for `-All` and for the existing non-positive-limit behavior.

Discovery now reports whether it is selecting up to a requested limit or scanning the full source tree, then reports the selected count before indexing.
