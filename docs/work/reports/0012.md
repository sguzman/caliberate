# Work report: 0012 library query filter parity

## Summary

Added typed DB- and library-domain metadata filters for Authors, Tags, Series, Publishers, Ratings, and Languages. Every active filter contributes an ANDed correlated `EXISTS` or `NOT EXISTS` predicate shared by result and count queries, preserving row cardinality and existing query/sort/pagination behavior.

## Exact Include/Exclude semantics

- Authors, Tags, Series, Publishers, and Languages use parameterized case-insensitive substring matching against related values.
- Ratings use exact numeric equality for integer ratings from 0 through 10; invalid or out-of-range values return a clear validation error.
- Include requires a matching related value.
- Exclude requires no matching related value, so missing relations pass Exclude and fail Include.
- Multiple filters, including multiple filters in the same category, are joined with AND.
- Legacy positive query fields remain separate and are also applied when combined with structured filters.
