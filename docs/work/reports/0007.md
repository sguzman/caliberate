# 0007 — Library-domain structured query and facets

## Summary

- Added the public `caliberate_library::query` module with `LibraryQuery`, `LibraryFacetKind`, and `LibraryFacetValue` domain types.
- Added builder methods and an internal conversion from `LibraryQuery` to the existing database `BookQuery`.
- Extended `LibraryCatalog` with `query_books` and `list_facets`, delegating all query and category behavior to existing database methods.
- Added focused temporary-database tests covering title, format, author, tag, and limit filtering plus author/tag facet names and counts.
