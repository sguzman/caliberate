# 0016.2 implementation report

## Runtime failure and correction

Human acceptance of task 0016.1 against the real Windows/WSL source failed with `invalid uri authority: wsl%24`. SQLite rejected the encoded `file://wsl%24/...` authority; this is not a Calibre schema failure. SQLite was not rebuilt with `SQLITE_ALLOW_URI_AUTHORITY`.

Explicit static-source mode now classifies canonical Windows UNC paths, including `\\wsl$\\...` and verbatim `\\?\\UNC\\...`, before URI construction. On Windows UNC paths it opens the ordinary UNC metadata path with `SQLITE_OPEN_READ_ONLY` and the built-in `win32-none` VFS, avoiding URI authority parsing. On normal local paths it retains `file:<encoded-path>?mode=ro&immutable=1` with `SQLITE_OPEN_READ_ONLY | SQLITE_OPEN_URI`. Both paths execute `PRAGMA query_only = ON`.

Normal `CalibreLibraryBackend::open()` remains locking read-only by default. Static mode remains explicit opt-in through the existing `--calibre-library-immutable` flag; there is no fallback and no `nolock=1`. The static warning remains explicit that the source must not change while Caliberate is running. SQLite sidecars are observed/logged only and never modified or deleted.

## Tests and validation

Synthetic tests cover UNC/WSL/verbatim-UNC classification, drive-path rejection, unchanged local immutable URI behavior, direct bundled `win32-none` VFS fixture opening on Windows, read-only/query-only behavior, normal locking mode, existing server/OPDS/download behavior, and CLI static-mode safety. The direct VFS test confirms the bundled build provides `win32-none`; policy selection avoids constructing an authority URI for UNC paths.

## Risks and unverified behavior

The real WSL/UNC runtime remains pending human acceptance. The UNC static branch uses the read-only `win32-none` VFS rather than SQLite `immutable=1`; it therefore does not provide immutable change-detection semantics. It is safe only when the source and SQLite sidecars remain static for the process lifetime. Existing GUI warnings are unchanged and outside scope.

No real Calibre library was accessed, modified, or deleted.
