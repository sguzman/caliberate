# 0020 implementation report

## Summary

Extended `LibraryBookSummary` additively with source-neutral `formats` while
retaining the existing primary `format` and `path` compatibility fields.
Attached Calibre summary pages now load all page IDs' `data` rows through a
bounded, parameterized batch helper, ordered by `book, data.id`, with lowercase
normalization, lowest-ID case-deduplication, and safe size conversion. No
summary path calls `list_formats` per book. Managed Database summaries derive
the one canonical format directly from the already-loaded summary record;
empty-format records remain empty.

The JSON browse and structured-query summary DTOs now add `format_count` and
path-free `formats` entries with `format` and optional `size_bytes`. Detail and
`/formats` DTOs, search DTOs, OPDS behavior, GUI behavior, and search semantics
remain unchanged. Documentation records the batched large-library discovery
contract.

## Evidence

Synthetic attached-Calibre tests cover PDF/EPUB/MOBI service order and sizes,
primary-format compatibility, case-only duplicate suppression, negative/NULL
size safety, metadata-only books, requested ordering, total/limit/offset
semantics, a 100-book page, and unchanged metadata bytes. The configured
Database test proves one normalized canonical format with no format inference
from assets. JSON tests cover GET and POST summary fields, three-format order,
metadata-only zero formats, path absence, and retained richer detail/content
behavior. The batch implementation uses bounded chunks of 400 parameterized
IDs and does not call `list_formats` from summary paging.
