# 0001 — Windows input/output path identity

## Summary

Updated `ebook-convert` path validation to compare the canonical filesystem
paths when the output already exists. This makes an existing input/output file
pair compare equal despite Windows path spelling differences such as the
extended `\\?\` prefix. The existing identical-path error text is unchanged.

## Files changed

- `crates/app/src/bin/ebook-convert.rs`
- `docs/work/active/0001-windows-path-identity.md` (moved to `docs/work/done/` after validation)
- `docs/work/reports/0001.md`

## Risks and caveats

The implementation canonicalizes only an existing output path, preserving
the behavior for new output paths. Native Windows behavior was verified by the
focused regression and full workspace suite in this environment. The prior
unrelated modification to `config/control-plane.toml` was left untouched.
