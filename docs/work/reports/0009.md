# 0009 — Rich library book-summary read model

## Summary

- Added `BookSummaryRecord` and `Database::search_book_summaries_query` for paged rich book rows.
- Batch-loaded extras and all requested relation families for the page using parameterized ID lists, preserving the base query order and avoiding N+1 metadata lookups.
- Added library-domain summary types and `LibraryCatalog::query_summary_page`, including required date and series mappings.
- Added focused DB and library tests covering metadata, relation multiplicity, page order/limits, empty pages, totals, and domain mapping.

## Batched metadata loading

`search_book_summaries_query` first obtains the paged base rows, returns immediately for an empty page, then performs a fixed number of page-wide queries for extras, authors, tags, series, publishers, ratings, and languages. Every page ID is bound as a SQL parameter. No per-book metadata getter is called inside the result-mapping loop.
