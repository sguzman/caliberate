# 0015 implementation report

## Summary

Added caliberate_library::calibre::CalibreLibraryBackend, a source-native,
read-only LibraryBackend for modern Calibre libraries. It opens only
<library_root>/metadata.db with SQLite read-only flags and enables
connection-level PRAGMA query_only = ON.

## Architecture and behavior

- The adapter is isolated in crates/library/src/calibre.rs; no GUI, server,
  OPDS, or ServerState behavior was changed.
- Construction validates only the required modern Calibre base tables and
  columns, with explicit incompatible-schema errors.
- All reads use direct, parameterized SQL against base tables. No Caliberate
  database opening, migrations, writes, Calibre views, user-defined SQLite
  functions, recursive scanning, or connection pooling are used.
- The current domain's single-format projection consistently selects the
  smallest data.id, lowercases its format, and returns empty format/path for
  metadata-only books.
- Content locators validate rooted/parent-traversal book paths and filename
  separators before resolving under the configured library root, and return
  storage_mode = Some(reference) without opening the ebook.
- Search, legacy filters, structured Include/Exclude filters, escaped literal
  string matching, numeric rating validation, all established sort fields,
  paging totals, global facets, and summary metadata are implemented.
- Summary relation data is bulk-loaded for the selected page IDs rather than
  loaded with one query per book.

## Tests

The module includes synthetic temporary Calibre fixtures containing the
canonical books/data schema and relation tables. Tests cover modern-schema
acceptance, missing metadata DB, source byte preservation, primary format
projection, search, summary, facets, filtering, and unsafe source paths.
No real Calibre library was accessed.

## Validation

All commands were run on native Windows and passed:

- cargo fmt --check
- cargo test -p caliberate-library — 18 tests passed
- cargo test -p caliberate-server — 6 tests passed
- cargo check --workspace --locked
- cargo test --workspace --locked — all workspace tests passed

The workspace check emitted the existing GUI deprecation/unused/dead-code
warnings; no new warning was introduced by the backend.

## Risks and unverified behavior

Performance was not measured against the user's real library. Runtime
compatibility was tested only against the specified synthetic modern schema;
unlisted Calibre schema variants and real-library filesystem peculiarities
remain unverified. The compatibility projection intentionally exposes only
one format until a later domain-model task expands it.
